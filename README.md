# Tour Guide Journey of Franciss Nerosa

A responsive HTML, CSS, and JavaScript website with a modular grid of four mountain destinations.

## Files
- `index.html` — page content
- `style.css` — grid layout and responsive design
- `script.js` — opens Google Maps directions when a destination card is clicked
- `images/` — cropped mountain thumbnails from the reference screenshots you supplied

## Run locally
1. Extract the ZIP file.
2. Open the `tour-guide-journey` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Click any mountain card to open Google Maps directions.

## Free GitHub Pages deployment
1. Sign in to GitHub and create a **public** repository named `tour-guide-journey`.
2. Upload `index.html`, `style.css`, `script.js`, and the complete `images` folder. Keep the same folder structure.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will look like `https://YOUR-USERNAME.github.io/tour-guide-journey/`.

## Notes
- Clicking a card opens Google Maps in a new tab. The browser/Maps may ask for location permission to show directions from your current location.
- Check the exact destination pin in Google Maps before hiking; place names and plus codes may be ambiguous.
- Ratings shown are copied from your supplied screenshots and have not been independently verified.
